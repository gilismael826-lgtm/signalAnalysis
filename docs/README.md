# EMG/IMU 信号接收与分析系统

这是一个用于接收、解析和可视化唯理EMG腕带数据的Python程序。该系统支持8通道EMG和6轴IMU数据的实时处理，并集成了智能手势识别功能。

## 功能特性

### 核心功能
- 图形化用户界面
- 串口自动检测和选择
- 实时数据可视化（EMG波形 + IMU柱状图）
- 数据采集控制（开始/停止）
- CSV/NPY格式数据保存
- 信号预处理功能（去趋势、滤波、归一化）

### 智能手势识别
- **自动多模型训练**：一键训练SVM、KNN、随机森林、MLP、集成学习、梯度提升6种算法
- **智能模型选择**：自动评估并选择最优模型
- **集成预测**：支持加权投票、自适应、最优模型三种策略
- **实时识别**：基于滑动窗口的实时手势识别

### 数据标注与管理
- 数据采集与标注工具
- 数据集管理（训练集/验证集/测试集分割）
- 数据增强功能
- 手势库管理

```bash

```

### 工作流程

```
1. 连接设备 → 主界面选择串口 → 开始采集
2. 数据标注 → 系统工具 → 数据标注 → 采集手势样本
3. 模型训练 → 系统工具 → 模型训练 → 自动训练所有模型
4. 实时识别 → 手势识别面板 → 启用识别
```

## 手势识别系统

### 支持的算法

| 算法 | 说明 | 特点 |
|------|------|------|
| **SVM** | 支持向量机 | RBF核，适合中小样本 |
| **KNN** | K近邻 | 距离加权投票 |
| **RF** | 随机森林 | 100棵树，支持特征重要性 |
| **MLP** | 多层感知机 | 3层隐藏层(256,128,64) |
| **Ensemble** | 集成学习 | SVM+KNN+RF软投票 |
| **GB** | 梯度提升 | 支持特征重要性 |

### 集成预测策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| `weighted_voting` | 加权投票 | 默认策略，综合所有模型 |
| `adaptive` | 自适应 | 高置信度用单模型，低置信度用集成 |
| `best_only` | 仅最优模型 | 对实时性要求极高的场景 |

### 预定义手势

系统内置12种手势：

| 手势 | 显示名 | 类别 | 难度 |
|------|--------|------|------|
| fist | 握拳 | 静态 | 简单 |
| open | 张开 | 静态 | 简单 |
| pinch | 捏合 | 静态 | 中等 |
| point | 指向 | 静态 | 中等 |
| rest | 静止 | 静态 | 简单 |
| wave | 挥手 | 动态 | 中等 |
| flex | 手腕弯曲 | 动态 | 简单 |
| extend | 手腕伸展 | 动态 | 简单 |
| pronation | 前臂内旋 | 动态 | 中等 |
| supination | 前臂外旋 | 动态 | 中等 |
| grab | 抓取 | 序列 | 困难 |
| release | 释放 | 序列 | 困难 |

### 自定义手势

1. 在"数据标注"界面输入新的手势名称
2. 采集足够样本（建议100+个）
3. 在"模型训练"界面训练模型
4. 新手势将自动被识别

## 数据格式

### EMG数据
- 8通道肌电信号
- 采样率：250 Hz
- 单位：微伏（μV）

### IMU数据
- 6轴惯性测量（3轴陀螺仪 + 3轴加速度计）
- 采样率：约104 Hz
- 陀螺仪单位：rad/s
- 加速度单位：m/s²

## 系统架构

### 数据流程

```
串口数据 → 主缓冲区(FIFO) → 实时显示
    ↓
采集缓冲区 → 特征提取 → 模型预测 → 手势识别
```

### 缓冲区机制

| 缓冲区 | 大小限制 | 用途 |
|--------|----------|------|
| `emg_buffer` | 10000样本 | 实时显示、分析 |
| `imu_buffer` | 10000样本 | 实时显示、分析 |
| `collection_emg_buffer` | 无限制 | 数据采集保存 |
| `collection_imu_buffer` | 无限制 | 数据采集保存 |

## 配置参数

### 识别参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 窗口大小 | 600ms | 时间窗口 |
| 置信度阈值 | 0.5 | 低于此值过滤结果 |
| 平滑窗口 | 5 | 结果平滑窗口大小 |
| 集成策略 | weighted_voting | 预测策略 |

### 训练参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 测试集比例 | 0.2 | 测试集占比 |

- `data/raw/labels.json` - 标签文件

### 模型文件
- `models/classifier_{algorithm}.pkl` - 各算法模型
- `models/ensemble_config.json` - 集成配置

## 注意事项

1. **数据采集**：确保主界面已开始采集数据
2. **样本数量**：每种手势至少需要20个样本才能训练
3. **推荐样本**：每种手势建议采集100-200个样本
4. **手势名称**：使用英文命名，如 thumb_up, peace

## 故障排除

### 无法连接设备
- 检查串口号是否正确
- 确认设备已正确连接
- 检查是否有其他程序占用串口

### 未采集到数据
- 确认主界面已点击"开始采集"
- 检查串口是否有数据传输
- 延长采集时长

### 模型训练失败
- 确保至少有2种不同的手势数据
- 检查样本数量是否足够
- 查看日志获取详细错误信息

# EMG/IMU 信号接收与分析系统

这是一个用于接收、解析和可视化唯理EMG腕带数据的Python程序。该系统支持8通道EMG和6轴IMU数据的实时处理。

## 功能特性

### 系统控制中心 (`system_control.py`)
- ✅ 图形化用户界面
- ✅ 串口自动检测和选择
- ✅ 实时数据可视化（EMG波形 + IMU柱状图）
- ✅ 数据采集控制（开始/停止）
- ✅ CSV格式数据保存
- ✅ 数据分析功能
- ✅ 系统设置管理
- ✅ 文档查看功能
- ✅ 完善的日志系统
- ✅ 信号预处理功能（去趋势、滤波、归一化）
- ✅ 原始信号和预处理信号独立显示
- ✅ 智能Y轴范围调整（根据归一化状态自动调整）

## 安装依赖

```bash
pip install -r src/requirements.txt
```

## 使用方法

### 启动系统控制中心

直接运行主程序：
```bash
python main.py
```

或者明确指定：
```bash
python main.py --control
```

### 列出可用串口

```bash
python main.py --list-ports
```

## 配置参数

在系统控制中心的"系统设置"中可以修改以下参数：

- 串口号
- 波特率（默认：921600）
- 数据保存目录
- 数据保存开关

## 数据格式

### EMG数据
- 8通道肌电信号
- 采样率：250 Hz（固定）
- 单位：微伏（μV）
- 数据范围：±8,388,607 μV

### IMU数据
- 6轴惯性测量（3轴陀螺仪 + 3轴加速度计）
- 采样率：动态估算（约100Hz）
- 陀螺仪单位：rad/s（弧度/秒）
- 加速度单位：m/s²（米/秒²）

## 输出文件

程序会创建以下输出文件：
- `emg_YYYYMMDD_HHMMSS.csv` - EMG数据文件
- `imu_YYYYMMDD_HHMMSS.csv` - IMU数据文件

### EMG CSV格式
```csv
timestamp,ch1,ch2,ch3,ch4,ch5,ch6,ch7,ch8
1234567890.123,100,200,300,400,500,600,700,800
1234567890.127,101,201,301,401,501,601,701,801
```

### IMU CSV格式
```csv
timestamp,gx,gy,gz,ax,ay,az
1234567890.123,0.1,0.2,0.3,1.0,2.0,3.0
1234567890.223,0.11,0.21,0.31,1.01,2.01,3.01
```

## 实时显示信息

## 注意事项

1. **串口权限**：确保有访问串口的权限
2. **端口设置**：根据实际设备修改串口号（Windows: COMx, Linux: /dev/ttyUSBx）
3. **性能要求**：实时绘图功能需要较好的CPU性能
4. **数据存储**：长时间运行会生成大量数据，注意磁盘空间
5. **窗口管理**：关闭GUI窗口会自动停止数据采集

## 故障排除

### 无法连接设备
- 检查串口号是否正确
- 确认设备已正确连接
- 检查是否有其他程序占用串口

### 无数据接收
- 确认设备已开机并正常工作
- 检查波特率设置是否正确
- 验证数据包格式是否匹配

### 绘图卡顿
- 关闭实时绘图功能
- 降低绘图更新频率
- 增加缓冲区大小

### 窗口无法启动
- 检查是否安装了tkinter
- 确认Python版本兼容性
- 查看日志文件获取错误信息

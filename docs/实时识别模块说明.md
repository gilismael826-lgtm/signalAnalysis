# 实时识别模块说明文档

## 概述

实时识别模块 (`realtime_recognizer.py`) 负责实时数据缓冲、特征提取和手势预测，是连接数据采集和手势分类的桥梁。

## 核心设计

### 1. 时间窗口对齐

由于EMG (250Hz) 和 IMU (104Hz) 采样率不同，采用时间窗口对齐策略：

```python
class RealtimeGestureRecognizer:
    def __init__(self, window_size_ms=600, emg_rate=250, imu_rate=104):
        self.window_size_ms = window_size_ms
        
        # 根据采样率计算各自的窗口样本数
        self.emg_window_samples = int(window_size_ms * emg_rate / 1000)  # 150 samples
        self.imu_window_samples = int(window_size_ms * imu_rate / 1000)  # 62 samples
        
        # 独立缓冲区（使用deque自动限制大小）
        self.emg_buffer = [deque(maxlen=self.emg_window_samples) for _ in range(8)]
        self.imu_buffer = [deque(maxlen=self.imu_window_samples) for _ in range(6)]
```

## 使用方法

### 基本使用

```python
from src.realtime_recognizer import RealtimeGestureRecognizer

# 创建识别器
recognizer = RealtimeGestureRecognizer(
    window_size_ms=600,        # 时间窗口大小
    slide_step=25,             # 滑动步长
    smoothing_window=5,        # 平滑窗口
    model_path='models/best_classifier.pkl'
)

# 在数据回调中更新
def on_data_received(emg_data, imu_data):
    result = recognizer.update(emg_data, imu_data)
    
    if result:
        print(f"手势: {result['gesture']}, 置信度: {result['confidence']:.2f}")
```

### 与主界面集成

```python
# 在main_window.py中集成
class MainWindow:
    def __init__(self):
        # ... 其他初始化 ...
        
        self.recognizer = RealtimeGestureRecognizer(
            model_path='models/gesture_classifier.pkl'
        )
        self.recognizer.set_prediction_callback(self.update_prediction_display)
    
    def on_serial_data(self, emg_data, imu_data):
        # 更新波形显示
        self.update_waveform(emg_data, imu_data)
        
        # 更新识别器并获取预测
        result = self.recognizer.update(emg_data, imu_data)
        
        if result:
            self.show_prediction(result)
    
    def update_prediction_display(self, result):
        self.prediction_label.config(text=f"手势: {result['gesture']}")
        self.confidence_label.config(text=f"置信度: {result['confidence']:.1%}")
```

### 使用回调

```python
def on_prediction(result):
    print(f"预测: {result['gesture']}")
    print(f"置信度: {result['confidence']:.2f}")
    print(f"耗时: {result['prediction_time_ms']:.1f}ms")

recognizer.set_prediction_callback(on_prediction)
```

## 参数配置

### 窗口大小

| 窗口大小 | EMG样本数 | IMU样本数 | 适用场景 |
|----------|-----------|-----------|----------|
| 300ms | 75 | 31 | 快速手势 |
| 600ms | 150 | 62 | 一般手势（推荐） |
| 1000ms | 250 | 104 | 慢速手势 |

### 滑动步长

| 步长 | 预测频率 | 重叠率 | 适用场景 |
|------|----------|--------|----------|
| 10 | 高 | 93% | 高灵敏度 |
| 25 | 中 | 83% | 一般应用（推荐） |
| 50 | 低 | 67% | 低延迟要求 |

### 平滑窗口

| 窗口大小 | 平滑程度 | 响应延迟 |
|----------|----------|----------|
| 3 | 轻度 | 低 |
| 5 | 中度（推荐） | 中 |
| 10 | 强 | 高 |

## 结果平滑算法

### 多数投票


### 加权置信度

```python
# 指数加权平均，新数据权重更高
weights = np.exp(np.linspace(0, 1, len(confidence_history)))
```

## 常见问题

### Q: 窗口未就绪时预测返回什么？

A: 返回 `None`，需要检查 `is_window_ready()` 或等待数据填充。

### Q: 如何调整预测灵敏度？

A: 减小 `slide_step` 可提高预测频率，增大 `smoothing_window` 可提高稳定性。

### Q: 如何处理预测延迟？

A: 减小 `window_size_ms` 和 `smoothing_window` 可降低延迟，但可能影响准确性。

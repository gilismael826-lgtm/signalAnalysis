# 预处理信号和原始信号独立参数配置说明

## 概述
为了解决预处理信号和原始信号使用不同参数范围的问题，系统现在支持为两种信号类型配置独立的缩放参数。

## 修改的文件

### 1. config.py
**新增配置参数：**
```python
# 预处理信号的独立缩放参数
processed_emg_y_min = -1.5
processed_emg_y_max = 1.5
processed_imu_y_min = -1.5
processed_imu_y_max = 1.5
```

**说明：**
- 预处理信号使用归一化后的数据范围，Y轴范围较小（[-1.5, 1.5]）
- 原始信号使用未归一化的数据范围，Y轴范围较大（[-50000, 50000]）
- 两种信号类型的参数完全独立，互不影响

### 2. plot_display.py
**修改内容：**
- 根据显示模式（`PREPROCESSING_DISPLAY_MODE`）选择不同的数据源和Y轴范围
- 原始信号模式：使用`config.emg_buffer`和`config.imu_buffer`，Y轴范围为`config.emg_y_min/max`和`config.imu_y_min/max`
- 预处理信号模式：使用`signal_processor.processed_emg_buffer`和`signal_processor.processed_imu_buffer`
  - 开启归一化时：Y轴范围为`config.processed_emg_y_min/max`和`config.processed_imu_y_min/max`（小范围）
  - 关闭归一化时：Y轴范围为`config.emg_y_min/max`和`config.imu_y_min/max`（与原始信号相似）

**关键代码：**
```python
if config.PREPROCESSING_DISPLAY_MODE == 'processed':
    emg_source = signal_processor.processed_emg_buffer
    imu_source = signal_processor.processed_imu_buffer
    signal_label = "预处理"
    
    # 根据是否开启归一化，选择合适的Y轴范围
    if signal_processor.normalize:
        # 开启归一化时，使用小范围
        emg_y_min_local = config.processed_emg_y_min
        emg_y_max_local = config.processed_emg_y_max
        imu_y_min_local = config.processed_imu_y_min
        imu_y_max_local = config.processed_imu_y_max
    else:
        # 关闭归一化时，使用与原始信号相似的范围
        emg_y_min_local = config.emg_y_min
        emg_y_max_local = config.emg_y_max
        imu_y_min_local = config.imu_y_min
        imu_y_max_local = config.imu_y_max
else:
    emg_source = config.emg_buffer
    imu_source = config.imu_buffer
    signal_label = "原始"
    emg_y_min_local = config.emg_y_min
    emg_y_max_local = config.emg_y_max
    imu_y_min_local = config.imu_y_min
    imu_y_max_local = config.imu_y_max
```

### 3. zoom_control.py
**新增函数：**

1. `get_current_y_range()`: 根据当前显示模式和归一化状态获取Y轴范围
2. `update_y_range()`: 更新Y轴范围，根据显示模式和归一化状态修改相应的配置参数
3. `quick_emg_zoom_in_current()`: 当前显示模式的EMG纵轴快速放大
4. `quick_emg_zoom_out_current()`: 当前显示模式的EMG纵轴快速缩小
5. `quick_imu_zoom_in_current()`: 当前显示模式的IMU纵轴快速放大
6. `quick_imu_zoom_out_current()`: 当前显示模式的IMU纵轴快速缩小
7. `update_zoom_info_display()`: 更新缩放信息显示，根据显示模式和归一化状态显示合适的单位

**修改内容：**
- 缩放控制窗口现在根据当前显示模式和归一化状态显示和修改相应的参数
- 重置按钮根据显示模式和归一化状态重置到不同的默认值
- 保存设置时根据显示模式和归一化状态修改相应的配置参数
- 缩放信息显示的单位会根据信号类型自动切换（μV/归一化）

### 4. main_window.py
**修改内容：**
- 导入新的缩放控制函数：`quick_emg_zoom_in_current`, `quick_emg_zoom_out_current`, `quick_imu_zoom_in_current`, `quick_imu_zoom_out_current`, `update_zoom_info_display`
- 快速缩放按钮现在使用新的函数，根据当前显示模式进行缩放
- 显示模式切换时自动更新缩放信息显示

**关键代码：**
```python
def change_display_mode():
    config.PREPROCESSING_DISPLAY_MODE = display_mode_var.get()
    from src.signal_processor import signal_processor
    
    # 当切换到预处理信号模式时，自动启用预处理
    if config.PREPROCESSING_DISPLAY_MODE == 'processed':
        config.PREPROCESSING_ENABLED = True
        preprocessing_enable_var.set(True)
        signal_processor.set_enabled(True)
        logger.info("已自动启用预处理功能")
    
    # 更新缩放信息显示
    update_zoom_info_display(emg_zoom_info_var, imu_zoom_info_var)
    
    logger.info(f"显示模式: {config.PREPROCESSING_DISPLAY_MODE}")
```

## 功能说明

### 1. 独立参数配置
- 原始信号和预处理信号使用完全独立的Y轴范围参数
- 修改原始信号参数不会影响预处理信号参数
- 修改预处理信号参数不会影响原始信号参数

### 2. 智能Y轴范围选择
- **预处理信号模式**：
  - 开启归一化：使用小范围（[-1.5, 1.5]，归一化单位）
  - 关闭归一化：使用与原始信号相似的范围（μV单位）
- **原始信号模式**：使用大范围（[-50000, 50000]，μV单位）

### 3. 自动参数切换
- 切换显示模式时，系统自动使用相应的参数
- 切换归一化开关时，系统自动调整Y轴范围
- 缩放信息显示自动更新为当前显示模式和归一化状态的参数
- 缩放操作根据当前显示模式和归一化状态独立工作

### 4. 合理的默认值
- 原始信号：Y轴范围为[-50000, 50000]（μV），适合未归一化的EMG信号
- 预处理信号（开启归一化）：Y轴范围为[-1.5, 1.5]（归一化），适合归一化后的信号
- 预处理信号（关闭归一化）：Y轴范围为[-50000, 50000]（μV），适合仅滤波未归一化的信号
- IMU信号：原始信号范围为[-5, 5]，预处理信号范围为[-1.5, 1.5]（归一化）或[-5, 5]（未归一化）

### 5. 性能优化
- 移除了update_plot函数内部的重复模块导入，避免了每秒20次的模块重复加载
- 确保切换显示模式和归一化开关时流畅运行，不会出现卡顿

## 使用方法

### 切换显示模式
1. 在主界面的"信号预处理"区域，选择"显示模式"
2. 选择"原始信号"查看未处理的原始信号
3. 选择"预处理信号"查看经过滤波和归一化处理的信号

### 调整缩放参数
1. 点击"波形缩放控制"按钮打开缩放控制窗口
2. 根据当前显示模式，调整相应的Y轴范围
3. 点击"保存"按钮保存设置
4. 点击"重置"按钮恢复默认值

### 快速缩放
1. 在主界面的"快速缩放"区域，点击"放大"或"缩小"按钮
2. 缩放操作会根据当前显示模式自动调整相应的参数

## 注意事项

1. 归一化后的信号范围应该在[-1, 1]附近，如果超出这个范围，可能需要检查归一化算法
2. 原始信号的Y轴范围应该很大，通常在[-50000, 50000]左右
3. 切换显示模式时，系统会自动更新缩放信息显示
4. 预处理信号模式下，系统会自动启用预处理功能
5. 预处理信号的Y轴范围会根据是否开启归一化自动调整：
   - 开启归一化：使用小范围（[-1.5, 1.5]）
   - 关闭归一化：使用与原始信号相似的范围（[-50000, 50000]）
6. 缩放信息显示的单位会根据信号类型自动切换（μV/归一化）

## 问题修复

### 问题1：预处理信号纵轴无法调节
**现象**：切换到预处理信号模式后，纵轴范围固定为[-1.5, 1.5]，无法调节

**原因**：
- 预处理信号总是使用归一化的小范围，无论是否开启了归一化
- 快速缩放按钮使用旧的函数，只修改原始信号的参数
- 缩放信息显示与实际波形图范围不一致

**解决方案**：
- 修改plot_display.py，根据是否开启归一化选择合适的Y轴范围
- 更新zoom_control.py的所有函数，支持根据归一化状态调整参数
- 修改main_window.py，使用新的缩放控制函数

### 问题2：切换模式后卡顿
**现象**：切换显示模式后，界面卡顿，波形图更新缓慢

**原因**：
- plot_display.py的update_plot函数内部重复导入signal_processor模块
- update_plot函数每50毫秒执行一次（每秒20次）
- 每次执行都进行模块导入，导致严重的性能问题

**解决方案**：
- 删除update_plot函数内部的重复导入语句
- 直接使用文件开头已经导入的signal_processor对象
- 避免每秒20次的模块重复加载

## 总结

通过为预处理信号和原始信号配置独立的缩放参数，系统现在可以更好地支持两种不同类型信号的显示和分析。用户可以根据需要自由切换显示模式，每种模式都有自己独立的缩放参数，互不影响。同时，系统会根据是否开启归一化自动调整Y轴范围，确保信号显示的合理性和可调节性。性能优化确保了切换显示模式和归一化开关时的流畅运行。

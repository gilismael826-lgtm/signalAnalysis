# 基于EMG和IMU信号的动态手势识别系统

## 1. 项目简介

### 1.1 项目背景

随着人机交互技术的快速发展，手势识别作为一种自然、直观的交互方式，正受到越来越多的关注。基于表面肌电信号（EMG）和惯性测量单元（IMU）的手势识别系统，能够通过采集人体肌肉活动和运动姿态信息，实现对用户手势的实时识别和响应，为康复医疗、虚拟现实、游戏娱乐等领域提供新的交互解决方案。

### 1.2 项目目标

本项目旨在开发一套基于EMG和IMU信号的动态手势识别系统，实现以下目标：

- 实时采集和处理EMG和IMU信号
- 提取有效的信号特征用于手势识别
- 构建准确的手势分类模型
- 实现低延迟的实时手势识别
- 提供友好的用户界面和交互体验

### 1.3 系统概述

系统主要由以下几个部分组成：

- **硬件采集模块**：EMG传感器（8通道）和IMU传感器（3轴陀螺仪+3轴加速度计）
- **数据传输模块**：串口通信（波特率921600）
- **信号处理模块**：滤波、特征提取、特征选择
- **手势识别模块**：分类器训练和实时预测
- **用户界面模块**：数据可视化和识别结果显示

## 3. 信号处理步骤

### 3.1 数据预处理

#### 3.1.1 滤波处理

- **带通滤波**：20-125Hz，去除噪声和基线漂移
- **陷波滤波**：50Hz，去除工频干扰

```python
# 带通滤波器实现示例
def bandpass_filter(data, lowcut=20.0, highcut=125.0, fs=250.0, order=4):
    nyq = 0.5 * fs
    low = lowcut / nyq
    high = highcut / nyq
    b, a = butter(order, [low, high], btype='band')
    y = lfilter(b, a, data)
    return y
```

#### 3.1.2 归一化

将EMG信号标准化到固定范围（如-1到1），确保不同强度的信号具有可比性。

```python
# 归一化函数示例
def normalize_signal(signal):
    min_val = np.min(signal)
    max_val = np.max(signal)
    normalized = 2 * (signal - min_val) / (max_val - min_val) - 1
    return normalized
```

#### 3.1.3 去趋势

去除信号中的线性或多项式趋势，减少基线漂移的影响。

```python
# 去趋势函数示例
def detrend_signal(signal):
    detrended = signal - np.polyval(np.polyfit(np.arange(len(signal)), signal, 1), np.arange(len(signal)))
    return detrended
```

### 3.2 特征提取

#### 3.2.1 时域特征

- **均值（Mean）**：信号的平均幅度
- **方差（Variance）**：信号的离散程度
- **峰峰值（Peak-to-Peak）**：信号的最大波动范围
- **积分肌电（IEMG）**：信号的能量积分
- **均方根（RMS）**：信号的有效值
- **斜率符号变化率（SSC）**：信号的变化频率

```python
# 时域特征提取函数示例
def extract_time_domain_features(data):
    features = {
        'mean': np.mean(data),
        'variance': np.var(data),
        'peak_to_peak': np.max(data) - np.min(data),
        'iemg': np.sum(np.abs(data)),
        'rms': np.sqrt(np.mean(np.square(data))),
        'ssc': calculate_ssc(data)
    }
    return features
```

#### 3.2.2 频域特征

- **频谱分析**：使用FFT将信号转换到频域
- **功率谱密度（PSD）**：信号在不同频率上的能量分布
- **中值频率（MF）**：功率谱的中值频率
- **平均频率（MPF）**：功率谱的平均频率

```python
# 频域特征提取函数示例
def extract_frequency_domain_features(data, fs=250):
    n = len(data)
    fft_result = np.fft.fft(data)
    frequencies = np.fft.fftfreq(n, 1/fs)[:n//2]
    power_spectrum = np.abs(fft_result)[:n//2] ** 2 / n
    
    # 计算中值频率和平均频率
    total_power = np.sum(power_spectrum)
    cumulative_power = np.cumsum(power_spectrum)
    mf = frequencies[np.argmax(cumulative_power >= total_power/2)]
    mpf = np.sum(frequencies * power_spectrum) / total_power
    
    features = {
        'mf': mf,
        'mpf': mpf,
        'peak_frequency': frequencies[np.argmax(power_spectrum)]
    }
    return features
```

#### 3.2.3 时频域特征

- **小波变换**：使用小波变换提取信号的时频特征
- **短时傅里叶变换（STFT）**：分析信号在不同时间窗口的频率内容

```python
# 时频域特征提取函数示例
def extract_time_frequency_features(data):
    # 使用小波变换
    coeffs = pywt.wavedec(data, 'db4', level=3)
    features = {}
    for i, coeff in enumerate(coeffs):
        features[f'wavelet_level{i}_mean'] = np.mean(np.abs(coeff))
        features[f'wavelet_level{i}_std'] = np.std(coeff)
    return features
```

#### 4.2.1 特征提取模块（feature_extractor.py）

```python
#!/usr/bin/env python3
"""
特征提取模块
负责从EMG和IMU信号中提取特征
"""

import numpy as np
import pywt
from scipy.signal import butter, lfilter

def butter_bandpass(lowcut, highcut, fs, order=4):
    """设计带通滤波器"""
    nyq = 0.5 * fs
    low = lowcut / nyq
    high = highcut / nyq
    b, a = butter(order, [low, high], btype='band')
    return b, a

def bandpass_filter(data, lowcut=20.0, highcut=125.0, fs=250.0, order=4):
    """应用带通滤波器"""
    b, a = butter_bandpass(lowcut, highcut, fs, order=order)
    y = lfilter(b, a, data)
    return y

def calculate_ssc(data):
    """计算斜率符号变化率"""
    ssc = 0
    for i in range(1, len(data)-1):
        if (data[i] - data[i-1]) * (data[i+1] - data[i]) < 0:
            ssc += 1
    return ssc

def extract_time_domain_features(data):
    """提取时域特征"""
    features = {
        'mean': np.mean(data),
        'variance': np.var(data),
        'peak_to_peak': np.max(data) - np.min(data),
        'iemg': np.sum(np.abs(data)),
        'rms': np.sqrt(np.mean(np.square(data))),
        'ssc': calculate_ssc(data)
    }
    return features

def extract_frequency_domain_features(data, fs=250):
    """提取频域特征"""
    n = len(data)
    fft_result = np.fft.fft(data)
    frequencies = np.fft.fftfreq(n, 1/fs)[:n//2]
    power_spectrum = np.abs(fft_result)[:n//2] ** 2 / n
    
    total_power = np.sum(power_spectrum)
    cumulative_power = np.cumsum(power_spectrum)
    mf = frequencies[np.argmax(cumulative_power >= total_power/2)]
    mpf = np.sum(frequencies * power_spectrum) / total_power
    
    features = {
        'mf': mf,
        'mpf': mpf,
        'peak_frequency': frequencies[np.argmax(power_spectrum)]
    }
    return features

def extract_time_frequency_features(data):
    """提取时频域特征"""
    coeffs = pywt.wavedec(data, 'db4', level=3)
    features = {}
    for i, coeff in enumerate(coeffs):
        features[f'wavelet_level{i}_mean'] = np.mean(np.abs(coeff))
        features[f'wavelet_level{i}_std'] = np.std(coeff)
    return features

def extract_features(emg_data, imu_data):
    """提取所有特征"""
    all_features = {}
    
    # 提取EMG特征
    for i, channel_data in enumerate(emg_data):
        # 滤波
        filtered_data = bandpass_filter(channel_data)
        # 时域特征
        td_features = extract_time_domain_features(filtered_data)
        for key, value in td_features.items():
            all_features[f'emg_{i}_{key}'] = value
        # 频域特征
        fd_features = extract_frequency_domain_features(filtered_data)
        for key, value in fd_features.items():
            all_features[f'emg_{i}_{key}'] = value
        # 时频域特征
        tfd_features = extract_time_frequency_features(filtered_data)
        for key, value in tfd_features.items():
            all_features[f'emg_{i}_{key}'] = value
    
    # 提取IMU特征
    for i, channel_data in enumerate(imu_data):
        # 时域特征
        td_features = extract_time_domain_features(channel_data)
        for key, value in td_features.items():
            all_features[f'imu_{i}_{key}'] = value
    
    return all_features
```

#### 4.2.2 手势分类模块（gesture_classifier.py）

```python
#!/usr/bin/env python3
"""
手势分类模块
负责手势分类器的训练和预测
"""

import numpy as np
from sklearn.svm import SVC
from sklearn.neighbors import KNeighborsClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import accuracy_score, classification_report
import joblib

class GestureClassifier:
    def __init__(self, algorithm='svm'):
        """初始化分类器"""
        self.algorithm = algorithm
        self.classifier = None
        self.labels = None
        
    def train(self, X, y, test_size=0.2):
        """训练分类器"""
        # 保存标签
        self.labels = np.unique(y)
        
        # 分割训练集和测试集
        X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=test_size, random_state=42)
        
        # 选择分类算法
        if self.algorithm == 'svm':
            self.classifier = SVC(kernel='rbf', C=1.0, gamma='scale', probability=True)
        elif self.algorithm == 'knn':
            self.classifier = KNeighborsClassifier(n_neighbors=5)
        elif self.algorithm == 'rf':
            self.classifier = RandomForestClassifier(n_estimators=100, random_state=42)
        else:
            raise ValueError('Unknown algorithm')
        
        # 训练模型
        self.classifier.fit(X_train, y_train)
        
        # 评估模型
        y_pred = self.classifier.predict(X_test)
        accuracy = accuracy_score(y_test, y_pred)
        report = classification_report(y_test, y_pred)
        
        print(f"Model accuracy: {accuracy:.4f}")
        print("Classification report:")
        print(report)
        
        # 交叉验证
        cv_scores = cross_val_score(self.classifier, X, y, cv=5)
        print(f"Cross-validation scores: {cv_scores}")
        print(f"Mean CV score: {np.mean(cv_scores):.4f}")
        
        return accuracy
    
    def predict(self, features):
        """预测手势"""
        if self.classifier is None:
            raise ValueError('Classifier not trained')
        
        prediction = self.classifier.predict(features)
        return prediction
    
    def predict_proba(self, features):
        """预测手势概率"""
        if self.classifier is None:
            raise ValueError('Classifier not trained')
        
        probabilities = self.classifier.predict_proba(features)
        return probabilities
    
    def save_model(self, filename):
        """保存模型"""
        if self.classifier is None:
            raise ValueError('Classifier not trained')
        
        joblib.dump({'classifier': self.classifier, 'labels': self.labels, 'algorithm': self.algorithm}, filename)
        print(f"Model saved to {filename}")
    
    def load_model(self, filename):
        """加载模型"""
        model_data = joblib.load(filename)
        self.classifier = model_data['classifier']
        self.labels = model_data['labels']
        self.algorithm = model_data['algorithm']
        print(f"Model loaded from {filename}")
```

#### 4.2.3 实时识别集成

在serial_comm.py中集成实时识别功能：

```python
# 在serial_comm.py中添加实时识别
from src.gesture_classifier import GestureClassifier
from src.feature_extractor import extract_features

# 加载预训练模型
classifier = GestureClassifier()
classifier.load_model('models/gesture_model.joblib')

# 滑动窗口参数
window_size = 600  # 600ms窗口
sample_rate = 250  # 250Hz采样率
window_samples = int(window_size * sample_rate / 1000)

# 数据窗口
emg_window = [[] for _ in range(8)]
imu_window = [[] for _ in range(6)]

def process_for_gesture_recognition(emg_data, imu_data):
    """处理数据用于手势识别"""
    # 更新窗口
    for i in range(8):
        emg_window[i].append(emg_data[i])
        if len(emg_window[i]) > window_samples:
            emg_window[i].pop(0)
    
    for i in range(6):
        imu_window[i].append(imu_data[i])
        if len(imu_window[i]) > window_samples:
            imu_window[i].pop(0)
    
    # 检查窗口是否已满
    if len(emg_window[0]) < window_samples:
        return None
    
    # 提取特征
    features = extract_features(emg_window, imu_window)
    
    # 转换为模型输入格式
    input_features = np.array([list(features.values())])
    
    # 预测手势
    try:
        prediction = classifier.predict(input_features)
        return prediction[0]
    except:
        return None
```

## 6. 测试与评估

### 6.1 测试方法

#### 6.1.1 数据采集测试

- **通信可靠性测试**：测试数据传输的可靠性和完整性

#### 6.1.2 信号处理测试

#### 6.1.3 手势识别测试

- **准确率测试**：测试系统对不同手势的识别准确率
- **实时性测试**：测量从手势执行到识别结果输出的延迟
- **鲁棒性测试**：测试系统在不同条件下的表现

### 6.2 评估指标

#### 6.2.1 识别性能指标

- **准确率（Accuracy）**：正确识别的样本数占总样本数的比例
- **精确率（Precision）**：预测为正类的样本中实际为正类的比例
- **召回率（Recall）**：实际为正类的样本中被正确预测的比例
- **F1分数**：精确率和召回率的调和平均
- **混淆矩阵**：展示不同手势的分类情况

#### 6.2.2 实时性指标

- **处理延迟**：从数据接收到识别结果输出的时间
- **帧率**：系统每秒能够处理的帧数
- **响应时间**：从手势执行到系统响应的时间

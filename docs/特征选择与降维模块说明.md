# 特征选择与降维模块说明文档

## 概述

特征选择与降维模块 (`feature_selector.py`) 负责对提取的高维特征进行降维和选择，提高模型性能并减少计算开销。

## 降维方法

### 1. PCA (主成分分析)

**原理**: 通过正交变换将数据投影到方差最大的方向

**特点**:
- 无监督方法
- 最大化方差保留
- 适用于特征间存在线性相关

**使用场景**:
- 特征维度很高时
- 特征间存在冗余
- 需要可视化高维数据

```python
from src.feature_selector import FeatureSelector

selector = FeatureSelector(n_components=20)

# 标准化数据
X_scaled = selector.fit_scaler(X)

# 应用PCA
X_pca = selector.apply_pca(X_scaled, n_components=20)

# 获取方差解释比例
info = selector.get_pca_info()
print(f"累计方差解释比例: {info['cumulative_variance_ratio'][-1]:.4f}")
```

**参数说明**:

| 参数 | 说明 | 默认值 |
|------|------|--------|
| n_components | 目标维度 | 初始化时设定 |
| svd_solver | SVD求解器 | 'auto' |

### 2. LDA (线性判别分析)

**原理**: 寻找能够最大化类别分离的投影方向

**特点**:
- 有监督方法
- 最大化类间方差/类内方差比
- 适用于分类任务

**限制**:
- 目标维度不能超过类别数-1

```python
# LDA需要标签
X_lda = selector.apply_lda(X_scaled, y, n_components=5)

# 获取LDA信息
info = selector.get_lda_info()
```

## 特征重要性评估

### 1. 随机森林特征重要性

基于随机森林的Gini不纯度下降计算特征重要性：

```python
importance = selector.get_feature_importance_rf(X, y, feature_names)

# 获取排名前10的特征
top_features = [feature_names[i] for i in importance['ranking'][:10]]
```

### 2. 互信息评估

计算特征与目标变量之间的互信息：

```python
importance = selector.get_feature_importance_mi(X, y, feature_names)
```

### 3. ANOVA F值评估

使用方差分析评估特征的区分能力：

```python
importance = selector.get_feature_importance_anova(X, y, feature_names)
print(f"P值: {importance['p_values']}")
```

### 4. 综合评估

结合多种方法给出综合排名：

```python
all_importance = selector.get_all_feature_importance(X, y, feature_names)

# 综合排名
combined_ranking = all_importance['combined']['ranking']
```

## 特征选择

### 选择K个最佳特征

```python
X_selected, indices = selector.select_k_best_features(
    X, y, k=50, score_func='f_classif'
)

print(f"选择的特征索引: {indices}")
```

**评分函数选项**:
- `f_classif`: ANOVA F值（默认）
- `mutual_info`: 互信息

## 完整工作流

```python
from src.feature_selector import FeatureSelector

# 1. 初始化
selector = FeatureSelector(n_components=50)

# 2. 标准化
X_scaled = selector.fit_scaler(X)

# 3. 特征重要性评估
importance = selector.get_all_feature_importance(X_scaled, y, feature_names)

# 4. 选择最佳特征
X_selected, selected_indices = selector.select_k_best_features(
    X_scaled, y, k=50
)

# 5. PCA降维
X_pca = selector.apply_pca(X_selected, n_components=20)

# 6. 可视化
selector.plot_pca_variance('pca_variance.png')
selector.plot_pca_2d(X_pca, y, 'pca_2d.png')

# 7. 保存模型
selector.save('feature_selector.pkl')
```

## 参数选择建议

### PCA维度选择

| 场景 | 建议方差保留比例 |
|------|------------------|
| 可视化 | 2-3个主成分 |
| 快速原型 | 90% |
| 高精度模型 | 95%+ |

### 特征数量选择

| 样本数 | 建议特征数 |
|--------|-----------|
| < 100 | < 20 |
| 100-1000 | 20-50 |
| 1000-10000 | 50-100 |
| > 10000 | 100+ |

# IMU信号预处理功能说明

## 概述

IMU（惯性测量单元）信号预处理是动态手势识别系统的关键环节。本文档详细说明了IMU信号预处理的功能、原理和配置方法。

## IMU信号特点

### 信号组成
IMU传感器包含6个通道：
- **3轴陀螺仪**：测量角速度（rad/s）
- **3轴加速度计**：测量加速度（m/s²）

### 信号特性
| 特性 | 说明 |
|------|------|
| 频率范围 | 0-20Hz（低频信号） |
| 主要噪声 | 传感器噪声、振动干扰 |
| 主要干扰 | 传感器漂移、重力分量 |
| 应用场景 | 运动姿态识别、手势识别 |

## 预处理功能

### 1. 去趋势（Detrending）

**目的**：去除传感器漂移和基线偏移

**原理**：使用线性拟合去除信号中的线性趋势

**效果**：
- 消除传感器漂移
- 稳定基线
- 提高信号质量

**实现**：
```python
def detrend(self, data):
    """去趋势"""
    detrended = data - np.polyval(
        np.polyfit(np.arange(len(data)), data, 1),
        np.arange(len(data))
    )
    return detrended
```

### 2. 低通滤波（Low-pass Filtering）

**目的**：去除高频噪声和振动干扰

**参数**：
- 截止频率：10Hz（默认）
- 滤波器类型：巴特沃斯低通滤波器
- 滤波器阶数：4阶（默认）

**原理**：使用巴特沃斯低通滤波器，保留10Hz以下的信号成分

**效果**：
- 去除高频噪声
- 抑制振动干扰
- 平滑信号波形

**实现**：
```python
def design_lowpass_filter(self, cutoff=10.0, order=4):
    """设计低通滤波器"""
    nyq = 0.5 * self.sample_rate
    high = cutoff / nyq
    b, a = butter(order, high, btype='low')
    self.lowpass_coeffs = (b, a)
    return b, a
```

**频率响应**：
- 0-5Hz：几乎无衰减（保留主要运动信息）
- 5-10Hz：轻微衰减（平滑过渡）
- >10Hz：显著衰减（去除高频噪声）

### 3. 移动平均滤波（Moving Average）

**目的**：进一步平滑数据，减少随机噪声

**参数**：
- 窗口大小：5个样本（默认）

**原理**：使用滑动窗口计算平均值

**效果**：
- 减少随机噪声
- 平滑信号波形
- 保持信号趋势

**实现**：
```python
def apply_moving_average(self, data, window_size=5):
    """应用移动平均滤波"""
    if len(data) < window_size:
        return data
    
    padded = np.pad(data, (window_size // 2, window_size // 2), mode='edge')
    smoothed = np.convolve(padded, np.ones(window_size) / window_size, mode='valid')
    return smoothed
```

### 4. 归一化（Normalization）

**目的**：将信号标准化到[-1, 1]范围

**原理**：使用最小-最大归一化

**效果**：
- 消除信号幅度差异
- 便于特征提取
- 提高识别准确率

**实现**：
```python
def apply_normalization(self, data):
    """应用归一化"""
    min_val = np.min(data)
    max_val = np.max(data)
    
    if max_val == min_val:
        return np.zeros_like(data)
    
    normalized = 2 * (data - min_val) / (max_val - min_val) - 1
    return normalized
```

## 预处理流程

### 完整处理流程

```
原始IMU数据
    ↓
去趋势（去除传感器漂移）
    ↓
低通滤波（去除高频噪声，截止频率10Hz）
    ↓
移动平均（平滑数据，窗口大小5）
    ↓
归一化（可选，标准化到[-1, 1]）
    ↓
预处理后的IMU数据
```

### 实时处理

系统使用滑动窗口进行实时处理：
- 缓冲区大小：500个样本（约2秒数据）
- 最小处理窗口：30个样本（约0.12秒）
- 处理延迟：<5ms

## 配置参数

### 在config.py中配置

```python
# IMU预处理配置（用于手势识别）
IMU_LOWPASS_ENABLED = True  # 启用低通滤波
IMU_LOWPASS_CUTOFF = 10.0  # 低通滤波截止频率（Hz）
IMU_LOWPASS_ORDER = 4  # 低通滤波阶数
IMU_MOVING_AVG_ENABLED = True  # 启用移动平均滤波
IMU_MOVING_AVG_WINDOW = 5  # 移动平均窗口大小
```

### 参数说明

| 参数 | 默认值 | 说明 | 调整建议 |
|------|--------|------|----------|
| `IMU_LOWPASS_ENABLED` | True | 是否启用低通滤波 | 一般保持启用 |
| `IMU_LOWPASS_CUTOFF` | 10.0 | 截止频率（Hz） | 5-15Hz，根据手势速度调整 |
| `IMU_LOWPASS_ORDER` | 4 | 滤波器阶数 | 2-6，阶数越高滤波越强但延迟越大 |
| `IMU_MOVING_AVG_ENABLED` | True | 是否启用移动平均 | 一般保持启用 |
| `IMU_MOVING_AVG_WINDOW` | 5 | 移动平均窗口 | 3-7，窗口越大越平滑但延迟越大 |

### 参数调整建议

#### 快速手势（如挥手）
- 截止频率：15Hz
- 移动平均窗口：3
- 滤波器阶数：2

#### 中速手势（如旋转）
- 截止频率：10Hz
- 移动平均窗口：5
- 滤波器阶数：4

#### 慢速手势（如握拳）
- 截止频率：5Hz
- 移动平均窗口：7
- 滤波器阶数：6

## 故障排除

### 常见问题

1. **信号延迟过大**
   - 减小滤波器阶数
   - 减小移动平均窗口
   - 检查系统性能

2. **信号过度平滑**
   - 提高截止频率
   - 减小移动平均窗口
   - 检查滤波器参数

3. **噪声仍然明显**
   - 降低截止频率
   - 增大移动平均窗口
   - 检查传感器质量

4. **手势识别准确率低**
   - 调整预处理参数
   - 增加训练数据
   - 优化特征提取

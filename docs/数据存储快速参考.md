# 数据存储快速参考指南

## 快速识别数据文件

### 文件名前缀规则

| 前缀 | 数据类型 | 说明 |
|------|---------|------|
| `raw_emg_` | 原始EMG数据 | 未处理的肌电信号，单位μV |
| `raw_imu_` | 原始IMU数据 | 未处理的惯性测量数据 |
| `processed_emg_` | 预处理EMG数据 | 经过滤波和归一化的肌电信号 |
| `processed_imu_` | 预处理IMU数据 | 经过滤波和归一化的惯性测量数据 |

### 文件名示例

```
raw_emg_20260208_192603_1.csv          # 原始EMG数据
raw_imu_20260208_192603_1.csv          # 原始IMU数据
processed_emg_20260208_192603_1.csv     # 预处理EMG数据
processed_imu_20260208_192603_1.csv     # 预处理IMU数据
```

### 文件名组成

```
[类型]_[传感器]_[日期]_[时间]_[序号].csv
```

- **类型**：`raw`（原始）或`processed`（预处理）
- **传感器**：`emg`（肌电）或`imu`（惯性测量）
- **日期**：YYYYMMDD格式（例如：20260208）
- **时间**：HHMMSS格式（例如：192603）
- **序号**：文件序号（从1开始递增）

## 数据特点对比

### 原始数据（raw_）

**EMG数据**：
- 单位：μV（微伏）
- 范围：通常±50000 μV
- 特点：包含原始信号的所有信息
- 用途：信号质量评估、噪声分析、设备校准

**IMU数据**：
- 陀螺仪：rad/s（弧度/秒）
- 加速度：m/s²（米/秒²）
- 特点：包含原始的惯性测量数据
- 用途：运动分析、姿态估计

### 预处理数据（processed_）

**EMG数据**：
- 开启归一化：归一化单位，范围[-1, 1]
- 关闭归一化：μV单位，范围与原始数据相似
- 特点：经过去趋势、滤波处理
- 用途：特征提取、模式识别、机器学习

**IMU数据**：
- 开启归一化：归一化单位，范围[-1, 1]
- 关闭归一化：与原始数据相同的单位
- 特点：经过去趋势处理
- 用途：运动分析、姿态估计

## 使用场景快速参考

### 场景1：需要原始数据
**文件**：`raw_emg_*.csv` 和 `raw_imu_*.csv`
**操作**：不启用信号预处理
**用途**：信号质量评估、噪声分析

### 场景2：需要预处理数据
**文件**：`processed_emg_*.csv` 和 `processed_imu_*.csv`
**操作**：启用信号预处理
**用途**：特征提取、模式识别

### 场景3：对比分析
**文件**：所有文件
**操作**：启用信号预处理
**用途**：对比原始和预处理数据

## 注意事项

1. **磁盘空间**：同时保存4个文件会占用更多空间
2. **文件轮换**：文件达到5MB时自动创建新文件
3. **时间戳**：文件名中的时间是创建时间，不是数据时间
4. **序号**：同一会话中序号递增，重启后重新开始

## 常见问题

### Q1：如何知道某个文件是原始数据还是预处理数据？
**A**：查看文件名前缀，`raw_`表示原始数据，`processed_`表示预处理数据。

### Q2：如何知道某个文件是EMG数据还是IMU数据？
**A**：查看文件名中的传感器标识，`emg`表示肌电数据，`imu`表示惯性测量数据。

### Q3：原始数据和预处理数据的时间戳是否一致？
**A**：基本一致，但预处理数据可能有轻微延迟（由于滤波处理）。

### Q4：可以只保存原始数据或只保存预处理数据吗？
**A**：当前版本会同时保存两种数据，这样可以保留所有信息供后续分析使用。

### Q5：如何删除旧的数据文件？
**A**：直接删除不需要的文件，或使用以下命令清理：
```bash
rm data/raw_emg_20260101_*.csv  # 删除特定日期的文件
```

## 🚀 使用方式

### 快速开始
```bash
# 激活虚拟环境
.\.venv\Scripts\activate

# 查看可用串口
python main.py --list-ports

# 运行基础版本
python main.py --basic --plot

# 运行增强版本（推荐）
python main.py --enhanced --plot
```

### 主要功能
- ✅ **实时数据采集**：8通道EMG + 6轴IMU
- ✅ **数据自动保存**：JSON格式，便于后续分析
- ✅ **实时可视化**：matplotlib动态绘图
- ✅ **信号特征提取**：RMS、方差、过零率等
- ✅ **时间轴对齐**：EMG和IMU数据插值对齐
- ✅ **错误处理**：串口连接异常自动重连

## 📊 系统特点

### 技术规格
- **EMG数据**：8通道，250Hz采样率，±8,388,607 μV范围
- **IMU数据**：6轴（3轴陀螺仪+3轴加速度计），约100Hz采样率
- **数据格式**：JSON，包含时间戳和传感器数据
- **波特率**：921600（高速串口通信）

### 性能优化
- 多线程数据接收
- 高效数据缓冲区管理
- 实时采样率估算
- 内存使用优化

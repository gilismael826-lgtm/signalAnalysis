## 系统概述

### 功能简介

本系统是一个基于EMG（肌电信号）和IMU（惯性测量单元）的实时手势识别系统，主要功能包括：

- **实时数据采集**: 通过串口接收EMG和IMU传感器数据
- **信号预处理**: 滤波、去噪、归一化处理
- **特征提取**: 提取时域、频域、时频域特征
- **手势分类**: 支持多种机器学习算法
- **实时识别**: 低延迟的实时手势预测
- **自定义手势**: 用户可自定义训练新手势

1. **克隆项目**

## 功能使用说明

### 1. 数据采集

#### 串口配置
- **串口号**: 根据设备管理器选择
- **波特率**: 默认921600
- **数据格式**: 自动解析

#### 数据保存
- 支持CSV格式保存
- 自动循环存储
- 可设置保存路径

### 2. 波形显示

#### 显示控制
- **横轴缩放**: 调节显示的数据点数量（1-10000）
- **纵轴缩放**: 快捷按钮调节幅度范围
- **通道选择**: 可选择显示特定通道

#### 预处理选项
- 滤波类型：低通/带通/高通
- 归一化：开启/关闭
- 显示模式：原始/处理后/对比

### 3. 手势识别

#### 模型加载
1. 点击"浏览"选择模型文件（.pkl）
2. 系统自动加载模型
3. 显示模型信息

#### 识别设置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 窗口大小 | 600ms | 数据窗口长度 |
| 滑动步长 | 25 | 预测间隔 |
| 平滑窗口 | 5 | 结果平滑 |
| 置信度阈值 | 0.5 | 最低置信度 |

### 4. 模型训练

#### 训练步骤
1. 准备训练数据集
2. 选择分类算法
3. 设置训练参数
4. 开始训练
5. 保存模型

#### 支持的算法
- **随机森林 (RF)**: 推荐，准确率高
- **支持向量机 (SVM)**: 适合小样本
- **K最近邻 (KNN)**: 简单快速
- **多层感知机 (MLP)**: 复杂模式
- **集成学习**: 最高准确率

### 5. 数据标注

#### 标注流程
1. 选择手势类型
2. 设置采集时长
3. 开始采集
4. 确认标签
5. 保存数据

#### 数据增强
- 高斯噪声
- 时间缩放
- 幅度缩放
- 时间平移

## 手势训练指南

### 预定义手势

| 手势 | 名称 | 难度 | 描述 |
|------|------|------|------|
| fist | 握拳 | 简单 | 手指握紧成拳 |
| open | 张开 | 简单 | 手指全部张开 |
| pinch | 捏合 | 中等 | 拇指与食指捏合 |
| point | 指向 | 中等 | 食指伸出指向 |
| rest | 静止 | 简单 | 手部自然放松 |
| wave | 挥手 | 中等 | 手腕左右摆动 |
| flex | 弯曲 | 简单 | 手腕向内弯曲 |
| extend | 伸展 | 简单 | 手腕向外伸展 |

### 训练建议

#### 样本数量
- 基础手势：每个手势 100+ 样本
- 复杂手势：每个手势 200+ 样本
- 自定义手势：每个手势 150+ 样本

#### 采集技巧
1. 保持一致的姿势
2. 每次采集间隔 1-2 秒
3. 避免过度疲劳
4. 多次重复采集

#### 数据质量
- 检查信号幅度
- 排除异常数据
- 确保标签正确
- 平衡各类别样本

### 自定义手势

#### 创建步骤
1. 打开"数据标注"窗口
2. 输入新手势名称
3. 按照引导采集数据
4. 训练自定义模型
5. 测试识别效果

## 常见问题解答

### Q1: 串口连接失败？

**解决方案**:
1. 检查设备是否正确连接
2. 确认串口号是否正确
3. 关闭其他占用串口的程序
4. 尝试重新插拔设备

### Q2: 波形显示异常？

**解决方案**:
1. 检查数据格式设置
2. 调整缩放参数
3. 重置显示设置
4. 检查传感器连接

### Q3: 识别准确率低？

**解决方案**:
1. 增加训练样本数量
2. 检查数据质量
3. 尝试不同算法
4. 调整特征选择
5. 使用数据增强

### Q4: 程序运行缓慢？

**解决方案**:
1. 关闭不必要的功能
2. 减少显示通道数
3. 降低采样率
4. 检查系统资源

### Q5: 模型训练失败？

**解决方案**:
1. 检查数据格式
2. 确保样本数量足够
3. 检查类别平衡
4. 查看错误日志

### Q6: 如何导入已有数据？

**解决方案**:
1. 将数据文件放入 `data/raw` 目录
2. 使用数据集管理器导入
3. 确保数据格式正确

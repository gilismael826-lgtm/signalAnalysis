# 快速开始指南

## 1. 环境准备

### 激活虚拟环境
```bash
# Windows
.\.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

### 安装依赖
```bash
pip install -r src/requirements.txt
```

## 2. 基本使用

### 查看可用串口
```bash
python main.py --list-ports
```

### 启动系统控制中心
```bash
# 直接启动
python main.py

# 或者明确指定
python main.py --control
```

## 3. 系统控制中心使用

### 数据采集
1. 选择串口号（点击"刷新"按钮更新列表）
2. 勾选"保存数据"选项（可选）
3. 点击"开始采集"按钮
4. 查看实时数据可视化
5. 点击"停止采集"按钮结束

### 数据分析
1. 点击"分析数据文件"按钮
2. 选择CSV数据文件
3. 查看数据统计信息

### 系统设置
1. 点击"系统设置"按钮
2. 修改波特率（默认：921600）
3. 修改数据目录（默认：data）
4. 点击"保存"按钮

### 查看文档
1. 点击"查看文档"按钮
2. 选择要查看的文档
3. 点击"打开"按钮查看内容

## 4. 界面说明

### 左侧控制面板
- **数据采集**：串口选择、开始/停止、数据保存
- **版本选择**：保留用于扩展功能
- **数据分析**：分析数据文件、查看统计
- **系统工具**：查看文档、系统设置

### 右侧图表区域
- **EMG波形**：8个通道实时波形图
- **IMU数据**：6个通道柱状图
- **自动更新**：50ms刷新频率

### 底部信息栏
- **EMG信息**：8通道，单位μV
- **IMU信息**：6通道，单位rad/s、m/s²
- **波特率**：921600

## 5. 常见问题

### 无法连接设备
1. 检查串口号是否正确：`python main.py --list-ports`
2. 确认设备已正确连接
3. 检查是否有其他程序占用串口

### 没有数据接收
1. 确认设备已开机
2. 检查波特率设置（默认921600）
3. 验证数据包格式是否匹配

### 绘图卡顿
1. 关闭实时绘图功能
2. 降低绘图更新频率
3. 增加缓冲区大小

### 窗口无法启动
1. 检查是否安装了tkinter
2. 确认Python版本兼容性
3. 查看日志文件获取错误信息

### 数据文件过大
1. 关闭数据保存功能
2. 定期清理旧数据文件
3. 增加数据文件大小限制

## 6. 数据文件使用

### 查看数据
- 使用Excel打开CSV文件
- 使用Python pandas读取：`pd.read_csv('data/emg_*.csv')`
- 使用MATLAB读取：`readmatrix()`或`readtable()`

### 数据分析
- 在系统控制中心中使用"分析数据文件"功能
- 查看数据统计信息
- 导出分析报告

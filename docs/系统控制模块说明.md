# 系统控制模块说明文档

## 概述

系统控制模块 (`system_control_module.py`) 负责系统核心功能，包括数据采集控制、系统设置、以及手势识别相关的模型训练、数据标注和识别设置功能。

## 模块架构

```
┌─────────────────────────────────────────────────────────────┐
│                  system_control_module                       │
├─────────────────────────────────────────────────────────────┤
│  数据采集控制                                                │
│  ├── start_acquisition()   开始数据采集                     │
│  ├── stop_acquisition()    停止数据采集                     │
│  └── clear_buffers()       清空数据缓冲区                   │
├─────────────────────────────────────────────────────────────┤
│  系统设置                                                    │
│  ├── export_config()       导出配置                         │
│  ├── analyze_data()        分析数据                         │
│  ├── view_documentation()  查看文档                         │
│  └── system_settings()     系统设置                         │
├─────────────────────────────────────────────────────────────┤
│  手势识别功能                                                │
│  ├── open_model_training()     打开模型训练窗口             │
│  ├── open_data_labeling()      打开数据标注窗口             │
│  ├── open_recognition_settings() 打开识别设置窗口           │
│  └── get_recognition_functions() 获取识别函数列表           │
└─────────────────────────────────────────────────────────────┘
```

## 数据采集控制

### start_acquisition

开始数据采集：

```python
from src.system_control_module import start_acquisition

start_acquisition(
    root,           # Tkinter根窗口
    port_var,       # 串口号变量
    save_var,       # 保存数据变量
    status_var,     # 状态变量
    status_label,   # 状态标签
    start_btn,      # 开始按钮
    stop_btn,       # 停止按钮
    update_plot_func  # 更新图表函数
)
```

### stop_acquisition

停止数据采集：

```python
from src.system_control_module import stop_acquisition

stop_acquisition(
    status_var,     # 状态变量
    status_label,   # 状态标签
    start_btn,      # 开始按钮
    stop_btn        # 停止按钮
)
```

### clear_buffers

清空数据缓冲区：

```python
from src.system_control_module import clear_buffers

clear_buffers()  # 显示提示信息
```

## 手势识别功能

### open_model_training

打开模型训练窗口：

```python
from src.system_control_module import open_model_training

open_model_training(root)
```

**功能**:
- 数据集路径选择
- 算法选择（RF/SVM/KNN/MLP/集成学习）
- 训练参数设置
- 训练进度显示
- 模型自动保存

**界面**:
```
┌─────────────────────────────────────────┐
│              模型训练                    │
├─────────────────────────────────────────┤
│  数据集                                  │
│  ┌─────────────────────────────────────┐│

│  └─────────────────────────────────────┘│
├─────────────────────────────────────────┤
│  算法设置                                │
│  ○ 随机森林 (RF)                         │
│  ○ 支持向量机 (SVM)                      │
│  ○ K最近邻 (KNN)                         │

│  ○ 集成学习                              │

```

### open_data_labeling

打开数据标注窗口：

```python
from src.system_control_module import open_data_labeling

open_data_labeling(root)
```

**功能**:
- 手势类型选择
- 受试者信息录入
- 采集时长设置
- 数据统计显示

**支持的手势类型**:
- fist (握拳)
- open (张开)
- pinch (捏合)
- wave (挥手)
- point (指向)
- flex (弯曲)
- extend (伸展)
- rest (静止)

### open_recognition_settings

打开识别设置窗口：

```python
from src.system_control_module import open_recognition_settings

open_recognition_settings(root, recognizer)
```

**功能**:
- 窗口大小设置
- 滑动步长设置
- 平滑窗口设置
- 置信度阈值设置
- 模型信息显示

**参数说明**:

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 窗口大小 | 600ms | 数据窗口长度 |
| 滑动步长 | 25 | 每次预测移动的样本数 |
| 平滑窗口 | 5 | 结果平滑的历史窗口大小 |
| 置信度阈值 | 0.5 | 最低置信度要求 |

### get_recognition_functions

获取手势识别相关函数列表：


## 与主界面的集成

### 添加识别菜单

```python
from src.system_control_module import (
    open_model_training,
    open_data_labeling,
    open_recognition_settings
)

# 创建菜单
menu_bar = tk.Menu(root)

# 识别菜单
recognition_menu = tk.Menu(menu_bar, tearoff=0)
recognition_menu.add_command(label="模型训练", command=lambda: open_model_training(root))
recognition_menu.add_command(label="数据标注", command=lambda: open_data_labeling(root))
recognition_menu.add_separator()
recognition_menu.add_command(label="识别设置", command=lambda: open_recognition_settings(root, recognizer))
menu_bar.add_cascade(label="识别", menu=recognition_menu)
```

### 添加工具栏按钮

```python
# 工具栏
toolbar = ttk.Frame(root)
toolbar.pack(fill=tk.X)

ttk.Button(toolbar, text="模型训练", 
           command=lambda: open_model_training(root)).pack(side=tk.LEFT, padx=2)
ttk.Button(toolbar, text="数据标注", 
           command=lambda: open_data_labeling(root)).pack(side=tk.LEFT, padx=2)
```

## 注意事项

1. **线程安全**: 模型训练在独立线程中执行，避免阻塞UI
2. **依赖检查**: 使用前检查 `RECOGNITION_AVAILABLE` 确保模块可用
3. **路径处理**: 使用 `os.path` 处理跨平台路径问题
4. **资源释放**: 窗口关闭时正确释放资源

# 智能手势识别系统说明文档

## 概述

本系统实现了基于多模型集成学习的智能手势识别功能。系统会自动训练所有支持的机器学习模型，并根据各模型的性能自动选择最优模型或进行集成预测，无需用户手动选择模型。

## 核心特性

### 1. 自动多模型训练

系统支持以下6种分类算法，训练时会自动训练所有模型：

| 算法 | 说明 | 特点 |
|------|------|------|
| **SVM** | 支持向量机 | RBF核，适合中小样本，泛化能力强 |
| **KNN** | K近邻 | 距离加权投票，简单直观 |
| **RF** | 随机森林 | 100棵树，支持特征重要性分析 |
| **MLP** | 多层感知机 | 3层隐藏层(256,128,64)，适合复杂模式 |
| **Ensemble** | 集成学习 | SVM+KNN+RF软投票，综合多模型优势 |
| **GB** | 梯度提升 | 支持特征重要性，适合增量学习 |

### 2. 智能模型选择

训练完成后，系统会自动：

1. **评估所有模型性能**：综合考虑准确率、F1分数、精确率、召回率
2. **计算综合得分**：`得分 = 准确率×0.4 + F1×0.3 + 精确率×0.15 + 召回率×0.15`
3. **选择最优模型**：自动选择综合得分最高的模型作为主模型
4. **分配模型权重**：根据各模型得分分配集成预测时的权重

### 3. 集成预测策略

系统支持三种集成预测策略：

#### 3.1 加权投票 (weighted_voting) - 默认策略

```
最终预测 = Σ(模型概率 × 模型权重)
```

- 综合所有模型的预测概率
- 根据模型性能自动分配权重
- 适合大多数场景，稳定性高

#### 3.2 自适应策略 (adaptive)

```
if 最高置信度 >= 阈值:
    使用最优模型预测
else:
    使用加权投票集成预测
```

- 高置信度时使用单模型，速度快
- 低置信度时启用集成，提高准确性
- 平衡速度与准确率

#### 3.3 仅最优模型 (best_only)

- 仅使用综合得分最高的模型
- 适合对实时性要求极高的场景

## 使用方法

### 1. 训练模型

```python
from src.gesture_classifier import GestureClassifierManager
from src.feature_extractor import FeatureExtractor

# 准备数据
X = features  # 特征矩阵 (n_samples, n_features)
y = labels    # 标签向量 (n_samples,)

# 创建管理器并自动训练所有模型
manager = GestureClassifierManager(models_dir='models')

# 一键训练所有模型，自动选择最优
results = manager.train_all(X, y)

# 查看训练结果
print(f"最优模型: {manager.best_algorithm}")
print(f"模型权重: {manager.model_weights}")

# 保存所有模型
manager.save_all()
```

### 2. 实时识别

```python
from src.realtime_recognizer import RealtimeGestureRecognizer

# 方式1：加载集成模型（推荐）
recognizer = RealtimeGestureRecognizer(
    models_dir='models',
    ensemble_strategy='weighted_voting',  # 集成策略
    use_ensemble=True
)

# 方式2：加载单个模型
recognizer = RealtimeGestureRecognizer(
    model_path='models/best_model.pkl',
    use_ensemble=False
)

# 更新数据并获取预测结果
result = recognizer.update(emg_data, imu_data)

if result:
    print(f"手势: {result['gesture']}")
    print(f"置信度: {result['confidence']:.2f}")
    print(f"预测方法: {result['method']}")
    print(f"参与模型: {result.get('participating_models', [])}")
```

### 3. 单次预测

```python
# 集成预测
result = manager.predict_single_ensemble(
    features,
    strategy='weighted_voting'
)

print(f"预测: {result['prediction']}")
print(f"置信度: {result['confidence']:.2f}")
print(f"方法: {result['method']}")
```

## 配置参数

### GestureClassifierManager 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `models_dir` | str | 'models' | 模型保存目录 |
| `ensemble_enabled` | bool | True | 是否启用集成预测 |
| `min_confidence_for_ensemble` | float | 0.6 | 自适应模式的置信度阈值 |

### RealtimeGestureRecognizer 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `window_size_ms` | int | 600 | 时间窗口大小(毫秒) |
| `confidence_threshold` | float | 0.5 | 置信度阈值 |
| `smoothing_window` | int | 5 | 结果平滑窗口大小 |
| `ensemble_strategy` | str | 'weighted_voting' | 集成策略 |
| `use_ensemble` | bool | True | 是否使用集成预测 |

## 性能优化建议

### 1. 模型选择建议

| 场景 | 推荐策略 | 原因 |
|------|----------|------|
| 高准确率要求 | weighted_voting | 综合多模型，减少误判 |
| 高实时性要求 | best_only | 单模型预测，速度最快 |
| 平衡场景 | adaptive | 自适应选择，兼顾两者 |

### 2. 参数调优建议

- **置信度阈值**：建议设置在0.5-0.7之间，过低会增加误判，过高会漏检
- **平滑窗口**：建议设置3-7，过小不稳定，过大响应慢
- **时间窗口**：建议设置400-800ms，根据手势复杂度调整

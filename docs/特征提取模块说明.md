# 特征提取模块说明文档

## 概述

特征提取模块 (`feature_extractor.py`) 负责从EMG和IMU信号中提取时域、频域和时频域特征，是手势识别系统的核心组件之一。

## 模块架构

```
┌─────────────────────────────────────────────────────────────┐
│                    FeatureExtractor                         │
├─────────────────────────────────────────────────────────────┤
│  时域特征提取                                                │
│  ├── extract_mean()         均值                            │
│  ├── extract_variance()     方差                            │
│  ├── extract_std()          标准差                          │
│  ├── extract_rms()          均方根                          │
│  ├── extract_iemg()         积分肌电                        │
│  ├── extract_zc()           过零率                          │
│  ├── extract_ssc()          斜率符号变化率                  │
│  ├── extract_wl()           波形长度                        │
│  ├── extract_wamp()         Willison幅度                    │
│  ├── extract_mav()          平均绝对值                      │
│  └── extract_peak_to_peak() 峰峰值                          │
├─────────────────────────────────────────────────────────────┤
│  频域特征提取                                                │
│  ├── extract_fft_features()   FFT频域特征                   │
│  ├── extract_power_band()     频带功率                      │
│  └── extract_spectral_features() 频谱特征                   │
├─────────────────────────────────────────────────────────────┤
│  时频域特征提取                                              │
│  └── extract_wavelet_features() 小波特征                    │
├─────────────────────────────────────────────────────────────┤
│  通道特征提取                                                │
│  ├── extract_channel_features() 单通道特征                  │
│  ├── extract_emg_features()    EMG特征(8通道)               │
│  ├── extract_imu_features()    IMU特征(6通道)               │
│  └── extract_all_features()    全部特征融合                 │
└─────────────────────────────────────────────────────────────┘
```

## 特征列表

### 1. 时域特征 (13个/通道)

| 特征名称 | 方法 | 说明 | 公式 |
|---------|------|------|------|
| Mean | `extract_mean()` | 均值 | $\bar{x} = \frac{1}{N}\sum_{i=1}^{N}x_i$ |
| Variance | `extract_variance()` | 方差 | $\sigma^2 = \frac{1}{N}\sum_{i=1}^{N}(x_i-\bar{x})^2$ |
| STD | `extract_std()` | 标准差 | $\sigma = \sqrt{\sigma^2}$ |
| RMS | `extract_rms()` | 均方根 | $RMS = \sqrt{\frac{1}{N}\sum_{i=1}^{N}x_i^2}$ |
| IEMG | `extract_iemg()` | 积分肌电 | $IEMG = \sum_{i=1}^{N}\|x_i\|$ |
| ZC | `extract_zc()` | 过零率 | 过零点计数 |
| SSC | `extract_ssc()` | 斜率符号变化率 | 斜率符号变化计数 |
| WL | `extract_wl()` | 波形长度 | $WL = \sum_{i=1}^{N-1}\|x_{i+1}-x_i\|$ |
| WAMP | `extract_wamp()` | Willison幅度 | 幅度变化超阈值计数 |
| MAV | `extract_mav()` | 平均绝对值 | $MAV = \frac{1}{N}\sum_{i=1}^{N}\|x_i\|$ |
| Peak-to-Peak | `extract_peak_to_peak()` | 峰峰值 | $P2P = \max(x) - \min(x)$ |
| Kurtosis | `extract_kurtosis()` | 峰度 | 四阶矩统计量 |
| Skewness | `extract_skewness()` | 偏度 | 三阶矩统计量 |

### 2. 频域特征 (10个/通道)

| 特征名称 | 说明 |
|---------|------|
| Median Frequency | 中值频率（功率谱中位数对应频率） |
| Mean Power Frequency | 平均功率频率 |
| Peak Frequency | 峰值频率 |
| Spectral Energy | 频谱能量 |
| Spectral Entropy | 频谱熵 |
| Spectral Centroid | 频谱质心 |
| Spectral Spread | 频谱扩展 |
| Power 20-50Hz | 20-50Hz频带功率 |
| Power 50-100Hz | 50-100Hz频带功率 |
| Power 20-100Hz | 20-100Hz频带功率 |

### 3. 时频域特征 (小波特征)

使用Daubechies 4 (db4) 小波进行3层分解：

| 层级 | 特征 |
|------|------|
| cA3 | 近似系数均值、标准差、能量 |
| cD3 | 细节系数均值、标准差、能量 |
| cD2 | 细节系数均值、标准差、能量 |
| cD1 | 细节系数均值、标准差、能量 |

### 4. 跨通道特征

| 特征名称 | 说明 |
|---------|------|
| Cross-correlation | 通道间互相关 |
| RMS Ratio | RMS比值 |
| RMS Max | 最大RMS |
| RMS Min | 最小RMS |

## 使用方法

### 基本使用

```python
from src.feature_extractor import FeatureExtractor

# 创建特征提取器
extractor = FeatureExtractor(
    emg_sample_rate=250.0,  # EMG采样率
    imu_sample_rate=104.0   # IMU采样率
)

# EMG数据: shape (8, 150) - 8通道，150样本
emg_data = np.random.randn(8, 150) * 1000

# IMU数据: shape (6, 62) - 6通道，62样本
imu_data = np.random.randn(6, 62) * 0.5

# 提取所有特征
features = extractor.extract_all_features(emg_data, imu_data)

print(f"特征数量: {len(features)}")
# 输出: 特征数量: 332
```

### 单通道特征提取

```python
# 提取单通道特征
channel_data = emg_data[0]  # 第一个EMG通道
sample_rate = 250.0

features = extractor.extract_channel_features(
    channel_data, 
    sample_rate, 
    prefix='emg_0'
)
```

### 仅EMG特征

```python
emg_features = extractor.extract_emg_features(emg_data)
# 返回8通道 × 每通道特征数
```

### 仅IMU特征

```python
imu_features = extractor.extract_imu_features(imu_data)
# 返回6通道 × 每通道特征数
```

## 采样率处理

本模块正确处理EMG (250Hz) 和 IMU (104Hz) 的不同采样率：

```python
class FeatureExtractor:
    def __init__(self, emg_sample_rate=250.0, imu_sample_rate=104.0):
        self.emg_sample_rate = emg_sample_rate
        self.imu_sample_rate = imu_sample_rate
    
    def extract_emg_features(self, emg_data):
        # 使用EMG采样率计算频域特征
        return self._extract_channel_features(
            emg_data[i], self.emg_sample_rate, ...
        )
    
    def extract_imu_features(self, imu_data):
        # 使用IMU采样率计算频域特征
        return self._extract_channel_features(
            imu_data[i], self.imu_sample_rate, ...
        )
```

## 特征命名规范

特征名称遵循以下格式：

```
{传感器}_{通道}_{特征名}

示例:
- emg_0_mean          # EMG通道0的均值
- emg_3_rms           # EMG通道3的RMS
- accel_1_median_frequency  # 加速度计通道1的中值频率
- gyro_2_spectral_entropy   # 陀螺仪通道2的频谱熵
```

## 性能优化建议

1. **批量处理**: 使用 `extract_all_features()` 一次性提取所有特征
2. **内存管理**: 对于长时间数据，建议分窗口处理
3. **并行计算**: 可使用多进程加速多通道特征提取

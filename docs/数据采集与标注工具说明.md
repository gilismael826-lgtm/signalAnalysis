# 数据采集与标注工具说明文档

## 概述

数据采集与标注工具 (`data_labeler.py`) 提供完整的数据采集、标注、数据集管理、数据增强、质量检查和可视化功能，支持手势识别系统的数据准备工作流程。

## 数据采集器 (GestureDataCollector)

### 功能说明

负责采集和保存手势数据，支持多种数据格式。

### 使用方法

```python
from src.data_labeler import GestureDataCollector

# 创建采集器
collector = GestureDataCollector(output_dir='data/raw')

# 开始采集会话
collector.start_session(
    gesture_name='fist',
    subject_id='subject_001'
)

# 添加数据（通常在数据回调中调用）
for _ in range(150):  # 150个样本点
    emg_data = get_emg_data()  # 8通道EMG数据
    imu_data = get_imu_data()  # 6通道IMU数据
    collector.add_data(emg_data, imu_data)

# 停止采集
session_data = collector.stop_session()

# 保存数据
filepath = collector.save_session(session_data, format='npy')
```

### 数据格式

| 格式 | 文件 | 说明 |
|------|------|------|
| NPY | `{id}_emg.npy`, `{id}_imu.npy`, `{id}_meta.json` | 推荐，高效 |
| CSV | `{id}_emg.csv`, `{id}_imu.csv` | 兼容性好 |
| JSON | `{id}.json` | 单文件，易读 |

### 会话信息

每个采集会话包含以下元数据：

```json
{
    "session_id": "fist_subject_001_20260221_120000",
    "gesture_name": "fist",
    "subject_id": "subject_001",
    "start_time": "2026-02-21T12:00:00",
    "end_time": "2026-02-21T12:00:03",
    "emg_samples": 750,
    "imu_samples": 312,
    "emg_sample_rate": 250.0,
    "imu_sample_rate": 104.0
}
```

## 标签标注工具 (GestureLabeler)

### 功能说明

管理数据标签，支持添加、删除、更新和批量标注。

### 使用方法

```python
from src.data_labeler import GestureLabeler

labeler = GestureLabeler(data_dir='data/raw')

# 添加标签
labeler.add_label(
    file_id='fist_subject_001_20260221_120000',
    gesture_name='fist',
    start_idx=0,
    end_idx=750,
    notes='高质量样本'
)

# 批量标注
file_ids = ['file_001', 'file_002', 'file_003']
labeler.batch_label(file_ids, 'open')

# 更新标签
labeler.update_label('file_001', 0, gesture_name='wave')

# 删除标签
labeler.remove_label('file_001', 0)

# 获取统计
stats = labeler.get_label_statistics()
print(f"总文件数: {stats['total_files']}")
print(f"各手势数量: {stats['gesture_counts']}")
```

### 标签文件格式

标签保存在 `data/raw/labels.json`：

```json
{
    "file_001": [
        {
            "gesture_name": "fist",
            "start_idx": 0,
            "end_idx": 750,
            "notes": "",
            "timestamp": "2026-02-21T12:00:00"
        }
    ]
}
```

## 数据集管理器 (DatasetManager)

### 功能说明

创建和管理训练数据集，自动分割训练/验证/测试集。

### 使用方法

```python
from src.data_labeler import DatasetManager

manager = DatasetManager(
    data_dir='data',
    output_dir='data/datasets'
)

# 创建数据集
dataset_info = manager.create_dataset(
    name='gesture_v1',
    gesture_names=['fist', 'open', 'pinch', 'wave'],
    train_ratio=0.7,
    val_ratio=0.15,
    test_ratio=0.15
)

# 列出数据集
datasets = manager.list_datasets()

# 加载数据集
train_data = manager.load_dataset('gesture_v1', 'train')
val_data = manager.load_dataset('gesture_v1', 'val')
test_data = manager.load_dataset('gesture_v1', 'test')

# 获取统计
stats = manager.get_dataset_statistics('gesture_v1')

# 删除数据集
manager.delete_dataset('gesture_v1')
```

## 数据增强器 (DataAugmenter)

### 增强方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `add_gaussian_noise()` | noise_level | 添加高斯噪声 |
| `time_scale()` | scale_factor | 时间缩放 |
| `amplitude_scale()` | scale_factor | 幅度缩放 |
| `time_shift()` | shift_samples | 时间平移 |

### 使用方法

```python
from src.data_labeler import DataAugmenter

augmenter = DataAugmenter()

# 单个增强操作
noisy_data = augmenter.add_gaussian_noise(data, noise_level=0.05)
scaled_data = augmenter.time_scale(data, scale_factor=1.2)

# EMG数据增强（组合多种方法）
aug_emg = augmenter.augment_emg(
    emg_data,
    noise_level=0.05,
    time_scale_range=(0.9, 1.1),
    amp_scale_range=(0.9, 1.1),
    time_shift_range=(-10, 10)
)

# IMU数据增强
aug_imu = augmenter.augment_imu(imu_data)

# 样本增强
aug_samples = augmenter.augment_sample(sample, num_augmentations=3)

# 数据集增强
augmented_data = augmenter.augment_dataset(
    samples,
    target_samples_per_gesture=100  # 或使用 augment_factor=2
)
```

### 增强参数建议

| 数据类型 | 噪声水平 | 时间缩放 | 幅度缩放 |
|----------|----------|----------|----------|
| EMG | 0.03-0.08 | 0.9-1.1 | 0.9-1.1 |
| IMU | 0.01-0.03 | 0.95-1.05 | 0.95-1.05 |

## 数据质量检查器 (DataQualityChecker)

### 功能说明

检查采集数据的质量，包括信号完整性、噪声水平、运动伪影等。

### 使用方法

```python
from src.data_labeler import DataQualityChecker

checker = DataQualityChecker(emg_sample_rate=250.0, imu_sample_rate=104.0)

# 综合质量检查
result = checker.check_data_quality(emg_data, imu_data, expected_duration_ms=3000)

print(f"质量分数: {result['quality_score']}")
print(f"质量等级: {result['quality_level']}")
print(f"问题列表: {result['issues']}")

# 单独检查
completeness = checker.check_signal_completeness(emg_data, imu_data)
noise = checker.check_noise_level(emg_data)
motion = checker.check_motion_artifact(emg_data, imu_data)
saturation = checker.check_signal_saturation(emg_data)
```

### 质量检查项目

| 检查项 | 说明 | 权重 |
|--------|------|------|
| 信号完整性 | 检查数据是否完整、有无缺失 | 30% |
| 噪声水平 | 检查各通道噪声水平 | 15% |
| 运动伪影 | 检查是否有运动伪影干扰 | 25% |
| 信号饱和 | 检查是否有信号饱和 | 20% |

### 质量等级

| 等级 | 分数范围 | 说明 |
|------|----------|------|
| excellent | 90-100 | 优秀，可直接使用 |
| good | 75-89 | 良好，可以使用 |
| fair | 60-74 | 一般，建议检查 |
| poor | 0-59 | 较差，建议重新采集 |

## 最佳实践

### 数据采集

1. **采集时长**: 每个手势建议采集 2-5 秒
2. **重复次数**: 每个手势至少采集 10-20 次
3. **手势多样性**: 至少采集 2 种不同的手势类型
4. **受试者**: 多人采集提高泛化能力
5. **环境**: 保持一致的采集环境

### 数据标注

1. **一致性**: 使用统一的手势名称
2. **时间区间**: 精确标注有效动作区间
3. **质量检查**: 标注后检查数据质量
4. **备注**: 添加有用的备注信息

### 数据集分割

1. **训练集**: 60-80%
2. **验证集**: 10-20%
3. **测试集**: 10-20%
4. **分层采样**: 确保各类别比例一致

### 数据增强

1. **适度增强**: 避免过度增强导致失真
2. **保持分布**: 增强后数据分布应与原始数据相似
3. **验证效果**: 检查增强是否提高模型性能

### 质量检查

1. **采集后检查**: 每次采集后进行质量检查
2. **问题记录**: 记录发现的问题和解决方案
3. **阈值调整**: 根据实际情况调整检查阈值

# 手势分类模块说明文档

## 概述

手势分类模块 (`gesture_classifier.py`) 负责训练、评估和使用机器学习模型进行手势分类，支持多种分类算法和模型管理功能。

## 支持的分类算法

### 1. SVM (支持向量机)

**特点**:
- 适用于中小规模数据集
- 核函数可处理非线性问题
- 支持概率输出

**默认参数**:
```python
{
    'kernel': 'rbf',
    'C': 1.0,
    'gamma': 'scale',
    'probability': True
}
```

**使用场景**: 高维特征、样本数适中

### 2. KNN (K最近邻)

**特点**:
- 简单直观
- 无需训练
- 距离加权投票

**默认参数**:
```python
{
    'n_neighbors': 5,
    'weights': 'distance',
    'metric': 'minkowski'
}
```

**使用场景**: 小规模数据集、快速原型

### 3. RF (随机森林)

**特点**:
- 集成学习方法
- 特征重要性可解释
- 抗过拟合

**默认参数**:
```python
{
    'n_estimators': 100,
    'max_depth': None,
    'random_state': 42
}
```

**使用场景**: 特征重要性分析、一般分类任务

### 4. MLP (多层感知机)

**特点**:
- 深度学习方法
- 自动特征学习
- 自适应学习率

**默认参数**:
```python
{
    'hidden_layer_sizes': (256, 128, 64),
    'activation': 'relu',
    'solver': 'adam',
    'max_iter': 500,
    'early_stopping': True
}
```

**使用场景**: 大规模数据、复杂模式

### 5. Ensemble (集成学习)

**特点**:
- 结合多个分类器
- 软投票机制
- 提高鲁棒性

**组成**: SVM + KNN + 随机森林

**使用场景**: 追求高准确率

### 6. GB (梯度提升)

**特点**:
- 串行集成
- 强大的预测能力
- 可调节学习率

**默认参数**:
```python
{
    'n_estimators': 100,
    'learning_rate': 0.1,
    'max_depth': 3
}
```

**使用场景**: 高精度需求

## 使用方法

### 基本训练

```python
from src.gesture_classifier import GestureClassifier

# 创建分类器
classifier = GestureClassifier(algorithm='rf')

# 训练
result = classifier.train(X, y, test_size=0.2)

print(f"训练准确率: {result['train_accuracy']:.4f}")
print(f"测试准确率: {result['test_accuracy']:.4f}")
print(f"F1分数: {result['f1_score']:.4f}")
```

### 交叉验证训练

```python
result = classifier.train_with_cv(X, y, n_splits=5)

print(f"交叉验证分数: {result['cv_scores']}")
print(f"平均准确率: {result['mean_accuracy']:.4f}")
```

### 网格搜索调参

```python
param_grid = {
    'C': [0.1, 1.0, 10.0],
    'kernel': ['rbf', 'linear']
}

result = classifier.grid_search(X, y, param_grid, cv=5)

print(f"最佳参数: {result['best_params']}")
print(f"最佳分数: {result['best_score']:.4f}")
```

### 预测

```python
# 批量预测
predictions = classifier.predict(X_new)

# 概率预测
probabilities = classifier.predict_proba(X_new)

# 单样本预测
result = classifier.predict_single(feature_dict)
print(f"预测: {result['prediction']}, 置信度: {result['confidence']:.4f}")
```

### 模型评估

```python
metrics = classifier.evaluate(X_test, y_test)

print(f"准确率: {metrics['accuracy']:.4f}")
print(f"精确率: {metrics['precision']:.4f}")
print(f"召回率: {metrics['recall']:.4f}")
print(f"F1分数: {metrics['f1_score']:.4f}")
```

### 模型保存与加载

```python
# 保存
classifier.save('models/gesture_classifier.pkl')

# 加载
classifier2 = GestureClassifier(algorithm='svm')
classifier2.load('models/gesture_classifier.pkl')
```

## 完整工作流示例

```python
from src.feature_extractor import FeatureExtractor
from src.feature_selector import FeatureSelector
from src.gesture_classifier import GestureClassifier, GestureClassifierManager

# 1. 特征提取
extractor = FeatureExtractor()
features_list = []
labels = []

for sample in training_data:
    features = extractor.extract_all_features(
        sample['emg_data'], 
        sample['imu_data']
    )
    features_list.append(list(features.values()))
    labels.append(sample['gesture_name'])

X = np.array(features_list)
y = np.array(labels)

# 2. 特征选择
selector = FeatureSelector(n_components=50)
X_selected, _ = selector.select_k_best_features(X, y, k=50)

# 3. 训练多个分类器
manager = GestureClassifierManager()
results = manager.train_all(X_selected, y)

# 4. 比较并保存最佳模型
comparison = manager.compare_results(results)
manager.save_best()

# 5. 预测新样本
prediction = manager.predict(X_new)
```

## 评估指标说明

| 指标 | 公式 | 说明 |
|------|------|------|
| Accuracy | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体准确率 |
| Precision | $\frac{TP}{TP+FP}$ | 预测为正的准确性 |
| Recall | $\frac{TP}{TP+FN}$ | 实际为正的召回率 |
| F1 Score | $\frac{2 \times P \times R}{P + R}$ | 精确率和召回率的调和平均 |

## 算法选择建议

| 场景 | 推荐算法 | 原因 |
|------|----------|------|
| 快速原型 | KNN | 简单快速 |
| 高维特征 | SVM | 核函数优势 |
| 特征重要性 | RF | 可解释性强 |
| 大规模数据 | MLP | 自动特征学习 |
| 最高精度 | Ensemble/GB | 集成优势 |

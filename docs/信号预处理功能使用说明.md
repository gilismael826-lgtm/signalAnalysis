# 信号预处理功能使用说明

## 功能概述

本系统已经实现了完整的信号预处理功能，支持对EMG和IMU信号进行实时预处理，并在波形图中显示预处理后的信号。

## 主要功能

### 1. 信号预处理模块（signal_processor.py）

提供了以下预处理功能：

#### EMG信号预处理
- **去趋势**：去除信号中的线性趋势，减少基线漂移
- **带通滤波**：20-100Hz带通滤波，去除高频噪声和低频漂移
- **陷波滤波**：50Hz陷波滤波，去除工频干扰
- **归一化**：将信号标准化到[-1, 1]范围，便于比较不同强度的信号

#### IMU信号预处理（用于手势识别）
- **去趋势**：去除传感器漂移
- **低通滤波**：10Hz低通滤波，去除高频噪声和振动干扰
- **移动平均滤波**：5点移动平均，平滑数据，减少噪声
- **归一化**：将信号标准化到[-1, 1]范围

### 2. 用户界面控制

在主界面的"信号预处理"控制面板中，用户可以：

- **启用/禁用预处理**：通过复选框控制是否启用预处理功能
- **选择滤波器类型**：
  - 带通滤波：仅应用带通滤波器
  - 陷波滤波：仅应用陷波滤波器
  - 双重滤波：同时应用带通和陷波滤波器
- **启用/禁用归一化**：通过复选框控制是否对信号进行归一化
- **切换显示模式**：
  - 原始信号：显示未经预处理的原始信号
  - 预处理信号：显示经过预处理的信号

### 3. 实时数据处理

系统支持实时数据预处理：

- **缓冲区管理**：使用滑动窗口（默认500个样本，约2秒数据）进行实时滤波
- **数据流处理**：在数据接收时自动进行预处理，无需手动触发
- **性能优化**：预处理后的数据独立存储，不影响原始数据的实时显示
- **智能Y轴范围**：根据是否开启归一化自动调整Y轴范围
  - 开启归一化：使用小范围（[-1.5, 1.5]）
  - 关闭归一化：使用与原始信号相似的范围（μV级别）

## 使用方法

### 基本使用步骤

1. **启动系统**：
   ```bash
   cd d:\Desktop\挑战杯\项目实现\信号接收\signalAnalysis
   python main.py
   ```

2. **连接硬件**：
   - 在"数据采集"面板中选择正确的串口号
   - 点击"刷新"按钮更新串口列表
   - 点击"开始采集"按钮开始数据采集

3. **启用预处理**：
   - 在"信号预处理"面板中勾选"启用预处理"
   - 选择合适的滤波器类型（推荐：双重滤波）
   - 根据需要勾选"归一化"

4. **切换显示模式**：
   - 在"显示模式"中选择"原始信号"或"预处理信号"
   - 观察波形图中的信号变化
   - Y轴标签会显示当前显示的模式（原始/预处理）

### 预处理效果对比

#### 原始信号特征
- 包含噪声和基线漂移
- 信号幅度可能变化较大
- 受工频干扰影响

#### 预处理后信号特征
- 噪声被有效滤除
- 基线稳定，漂移减少
- 工频干扰被抑制
- 信号更加平滑，便于分析

## 技术参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 采样率 | 250Hz | 系统采样频率 |
| EMG带通滤波范围 | 20-100Hz | 去除低频漂移和高频噪声 |
| EMG陷波滤波频率 | 50Hz | 去除工频干扰 |
| IMU低通滤波截止频率 | 10Hz | 去除高频噪声和振动干扰 |
| IMU移动平均窗口 | 5样本 | 平滑数据 |
| 滤波器阶数 | 4 | 巴特沃斯滤波器阶数 |
| 滑动窗口大小 | 500样本 | 约2秒数据 |

| 缓冲区 | 大小 | 说明 |

| 预处理EMG缓冲区 | 10000点 | 存储预处理EMG数据 |
| 预处理IMU缓冲区 | 10000点 | 存储预处理IMU数据 |
| 滤波缓冲区 | 500样本/通道 | 用于实时滤波的临时缓冲区 |

## 注意事项

1. **滤波器选择**：
   - **EMG信号**：
     - 带通滤波：适用于一般情况，去除噪声效果好
     - 陷波滤波：适用于工频干扰严重的情况
     - 双重滤波：综合效果最好，推荐使用
   - **IMU信号**：
     - 低通滤波：自动启用，去除高频噪声和振动干扰
     - 移动平均：自动启用，平滑数据
     - 适合手势识别应用

2. **归一化使用**：
   - 归一化会丢失信号的绝对幅度信息
   - 仅用于比较不同信号的特征分析
   - 如果需要信号绝对值，请禁用归一化
   - 归一化后信号范围应在[-1, 1]附近

3. **显示模式切换**：
   - 切换显示模式不会影响数据采集
   - 可以随时在原始信号和预处理信号之间切换
   - 两种信号同时存储，互不影响
   - 切换到预处理信号模式时，系统会自动启用预处理功能

4. **Y轴范围调整**：
   - 预处理信号的Y轴范围会根据是否开启归一化自动调整
   - 开启归一化：使用小范围（[-1.5, 1.5]，归一化单位）
   - 关闭归一化：使用与原始信号相似的范围（μV单位）
   - 缩放信息显示的单位会根据信号类型自动切换
   - 可以通过"波形缩放控制"窗口手动调整Y轴范围

5. **性能优化**：
   - 如果系统性能不足，可以禁用预处理
   - 减少滤波器阶数可以提高处理速度
   - 增大滑动窗口可以减少预处理频率
   - 系统已优化性能，切换显示模式和归一化开关时不会卡顿

6. **IMU预处理配置**：
   - IMU低通滤波默认启用，截止频率10Hz
   - IMU移动平均默认启用，窗口大小5个样本
   - 可在config.py中调整IMU预处理参数：
     - `IMU_LOWPASS_ENABLED`：启用/禁用低通滤波
     - `IMU_LOWPASS_CUTOFF`：设置截止频率（Hz）
     - `IMU_LOWPASS_ORDER`：设置滤波器阶数
     - `IMU_MOVING_AVG_ENABLED`：启用/禁用移动平均
     - `IMU_MOVING_AVG_WINDOW`：设置窗口大小

## 故障排除

### 常见问题

1. **预处理后信号为空**：
   - 检查是否启用了预处理
   - 确认滤波器参数是否正确
   - 查看日志中的错误信息

2. **信号失真**：
   - 检查滤波器频率范围是否合适
   - 尝试不同的滤波器类型
   - 调整滤波器阶数

3. **系统卡顿**：
   - 禁用不必要的预处理功能
   - 减小缓冲区大小
   - 检查系统资源使用情况

4. **显示不更新**：
   - 确认数据采集是否正常
   - 检查显示模式是否正确
   - 查看系统日志
